# SkillCraft Technology - Task 4

## Business Insights Report (EDA)

This project is part of my Data Analytics Internship at SkillCraft Technology.

### Work Completed

- Cleaned and checked the marketing campaign dataset
- Checked missing values and duplicate records
- Performed Exploratory Data Analysis (EDA)
- Analysed the marketing funnel
- Compared marketing channels using ROI
- Prepared a one-page business insights summary
- Added recommendations based on the analysis

### Tools Used

- Power BI
- Excel
- Data Analysis / EDA

### Dataset

Marketing Campaign Performance dataset.

### Main Insight

The analysis shows that the ROI of the major channels is quite close. Facebook had a slightly higher average ROI in the analysis, so it can receive slightly more focus while Website and Instagram continue to be used as supporting channels.

### Conclusion

The analysis showed that ROI should not be considered alone. Clicks, engagement and conversions should also be checked before making marketing budget decisions.
